# react-native-network-replay

A developer-friendly React Native library for API mocking, contract-based mock generation, and network request recording and replay. Build and test your UI without waiting for the backend.

## Installation


```sh
npm install react-native-network-replay
```


## Usage


```js
import { multiply } from 'react-native-network-replay';

// ...

const result = multiply(3, 7);
```
